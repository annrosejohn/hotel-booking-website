# 🌴 Dwellr – Luxury Resort Website

A modern and responsive luxury resort website designed to showcase premium accommodations, resort services, guest experiences, and booking inquiries.

## ✨ Features

- 🏝️ Full-screen hero image carousel
- 🏨 Featured accommodations
- 🛏️ Room categories with Bootstrap tabs
- 🔍 Room details using Bootstrap modals
- 🌿 Resort information and statistics
- 💆 Ayurvedic & wellness spa section
- 🏋️ Fitness center
- 🍽️ Fine dining restaurant
- 📶 High-speed Wi-Fi
- 🏊 Infinity pool
- 🚗 Concierge & valet services
- ⭐ Guest testimonials carousel
- 📋 Inquiry & reservation form
- 📍 Google Maps integration
- 📱 Responsive design
- ☰ Offcanvas navigation menu
- 🌐 Social media links

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5.3
- Bootstrap Icons
- Font Awesome
- Google Fonts
- JavaScript
- Bootstrap Carousel
- Bootstrap Modal
- Bootstrap Tabs
- Bootstrap Collapse
- Bootstrap Offcanvas
- Google Maps Embed
